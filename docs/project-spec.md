c# dcamp 포트폴리오 기업 대시보드 — 상세 스펙

## 프로젝트 개요

dcamp(디캠프, 은행권청년창업재단) 내부 임직원이 포트폴리오 기업(배치 프로그램 참여 스타트업)에 대해 빠르게 파악할 수 있는 기업 정보 대시보드를 만드는 프로젝트.

**핵심 가치**: 노션, 구글 드라이브, 내부 시스템 등 여러 곳에 흩어져 있는 기업 정보를 한 페이지에서 조회할 수 있게 하는 것.

**한 줄 요약**: 기업명을 검색하면 "이 팀이 뭐하는 곳이고 지금 어떤 상황인지" 3분 안에 파악 가능한 내부용 웹 도구.

## 사용자 & 시나리오

- **1순위 사용자**: dcamp 내부 임직원 (사업실, 경영지원 등)
- **주요 시나리오**:
  - 멘토 매칭 전 기업 현황 확인
  - 팀 간 정보 공유 (사업협력 ↔ 배치 ↔ 그로스)
  - 대표님/경영진 보고 시 기업 현황 빠른 조회
  - 외부 파트너(VC, 멘토) 미팅 전 브리핑 준비

## 대상 범위

- **파일럿**: 최근 2~3개 기수 배치 기업
- **향후 확장**: 전체 포트폴리오

## 기업 프로필 정보 구조

각 기업 페이지에 포함되어야 할 정보:

### 기본 정보 (거의 변하지 않는 것)
- 기업명 / 대표자명
- 서비스 한줄 소개
- 산업 분류 / 비즈니스 모델
- 배치 기수 / 선발 시기
- 팀 규모
- 홈페이지 / 서비스 URL

### 투자 & 성장 현황
- 투자 단계 (Pre-Seed / Seed / Series A 등)
- 누적 투자 유치액
- 주요 투자자
- 핵심 지표 (MAU, MRR, GMV 등 해당 기업에 맞는 것)

### 최근 현황 (주기적으로 업데이트되는 것)
- 최근 주요 이슈 / 마일스톤
- PO Weekly 기반 최근 성과 & 이슈
- 뉴스 / 언론 보도

### 멘토링 히스토리
- 멘토링 참여 이력 (누구에게, 어떤 주제로)
- 주요 피드백 요약
- 오피스아워 참여 이력

### dcamp 지원 이력
- 프로그램 참여 이력 (배치, 사업협력, 오피스아워 등)
- 공간 입주 여부
- 기타 지원 내역

## 데이터 소스

현재 데이터가 흩어져 있는 위치:

| 데이터 | 현재 위치 | 형태 | 비고 |
|--------|----------|------|------|
| 배치 지원서 / IR자료 | 구글 드라이브 | PDF, 문서 | 이미 보유 |
| 멘토링 기록 / 피드백 | 노션, 구글 시트 | 텍스트, 녹음 | 축적 중 |
| PO Weekly 운영 데이터 | 노션 | 데이터베이스 | Bi-Weekly 업데이트 |
| 기업 기본 정보 | 내부 DB / 노션 | 정형 데이터 | |
| 뉴스 / 외부 정보 | 웹 | 비정형 | 크롤링 또는 수동 |

## 기술 방향 (Phase별)

### Phase 1 — MVP (파일럿)
- 샘플 2~3개 기업으로 프로토타입
- 데이터는 수동으로 정리하여 JSON/CSV로 구성
- 정적 웹페이지로 검색 & 조회 기능 구현
- **목표**: 정보 구조와 UI가 실제로 쓸만한지 검증

### Phase 2 — 데이터 연동
- 노션 API, 구글 드라이브 API 연동으로 자동 데이터 수집
- 기업 정보 자동 업데이트 파이프라인 구축
- 검색 고도화 (산업별, 단계별 필터링)

### Phase 3 — AI 기능 추가
- 기업 정보 자연어 요약 (AI 멘토 프로젝트와 연결)
- "이 기업에 대해 알려줘" → 챗 인터페이스
- 멘토링 녹취 데이터 기반 인사이트 추가
- 유사 기업 추천

## 프로젝트 배경

이 프로젝트는 dcamp 대표님이 2026년 내 AI 멘토 베타 서비스 출시를 지시한 것에서 시작됨. 초기에는 "AI 멘토"로 시작했지만, 실무 검토를 거쳐 다음과 같이 리프레이밍:

- AS-IS: AI가 멘토를 대체하는 서비스
- TO-BE: 먼저 기업 정보를 잘 정리하고 조회할 수 있는 기반을 만들고, 그 위에 AI 기능을 얹는 방향

이 대시보드가 잘 되면:
1. 내부 업무 효율화 (즉시 효과)
2. 멘토 브리핑 도구로 확장 (Phase 2)
3. AI 멘토의 데이터 기반이 됨 (Phase 3)
4. 대표님께 단계적 진행 보고 가능

## 법적 고려사항

- 멘토링 녹음 데이터: 멘토링 신청 시 녹음 동의 조항 포함 (진행 중)
- 기업 정보: 배치 지원 시 정보 활용 동의 확인 필요
- 내부 임직원 전용 → 외부 공개 시 별도 법적 검토 필요
