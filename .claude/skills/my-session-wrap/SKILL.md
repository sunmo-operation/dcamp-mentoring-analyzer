```
┌─────────────────────────────────────────────────────────────┐

│                                                             │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ │
│  │ doc-updater  │ │ automation-  │ │ learning-    │ │ followup-    │ │

│  └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘ │
```

## Step 1: 변경 내용 확인

현재 세션의 작업 내역을 자동으로 파악한다.

### 실행 방법

1. `git status`로 변경/추가/삭제된 파일 목록을 확인한다
2. `git diff --stat`으로 각 파일의 변경량을 파악한다
3. 커밋되지 않은 변경 사항이 있는지 확인한다

### 변경 내용 요약 형식

아래 형식으로 변경 내용을 정리한다:

```
📋 세션 변경 요약
─────────────────
• 새로 만든 파일: (목록)
• 수정한 파일: (목록)
• 삭제한 파일: (목록)
• 커밋 안 된 변경: 있음/없음
```

> 이 요약 결과는 Phase 1의 4개 에이전트에게 전달되어 각자의 분석에 활용된다.

## Step 2: Phase 1 — 4개 분석 에이전트 (병렬 실행)

Step 1에서 파악한 변경 내용을 기반으로, 4개의 전문가 에이전트를 **동시에** 실행한다.
Task 도구로 4개 에이전트를 한 번에 호출하여 병렬 처리한다.

| 에이전트 | 역할 | 출력 |
|----------|------|------|
| doc-updater | 문서 업데이트 대상 탐색 | 📝 문서 업데이트 제안 |
| automation-scout | 반복 패턴 → 자동화 제안 | ⚡ 자동화 제안 |
| learning-extractor | 학습 내용 추출 | 🎓 오늘 배운 것 |
| followup-suggester | 후속 작업 제안 | 📌 다음에 할 일 |

> 각 에이전트의 상세 정의는 `references/agents.md` 참조.

### 병렬 실행 방법

4개 에이전트를 **하나의 메시지에서 동시에** Task 도구로 호출한다:

```
Task(doc-updater, subagent_type=Explore): Step 1 변경 요약을 바탕으로 문서 업데이트 대상 분석
Task(automation-scout, subagent_type=Explore): Step 1 변경 요약을 바탕으로 자동화 기회 분석
Task(learning-extractor, subagent_type=Explore): Step 1 변경 요약을 바탕으로 학습 내용 추출
Task(followup-suggester, subagent_type=Explore): Step 1 변경 요약을 바탕으로 후속 작업 제안
```

> 4개 에이전트는 서로 의존하지 않으므로 동시에 실행하여 시간을 절약한다.

## Step 3: Phase 2 — 검증 에이전트 (순차 실행)

Phase 1의 4개 에이전트 결과를 모두 받은 뒤, duplicate-checker 에이전트가 **순차적으로** 검증한다.

### Agent: duplicate-checker (중복 검증)

Phase 1의 모든 결과를 검토하여 중복을 처리한다:
- **완전 중복** → 제거 (동일 파일에 동일 작업)
- **부분 중복** → 병합 제안 (같은 파일, 다른 수정 내용)
- **중복 없음** → 그대로 통과

> 상세 검증 규칙은 `references/agents.md` 참조.

**순차 실행 이유**: Phase 1의 모든 결과가 모여야 비교할 수 있으므로, Phase 1 완료 후에 실행한다.

## Step 4: 결과 통합

Phase 1(4개 에이전트) + Phase 2(검증)의 결과를 하나로 정리하여 출력한다.

### 통합 보고서 형식

```
═══════════════════════════════════════
📊 세션 래핑 결과
═══════════════════════════════════════

📋 변경 요약
• 새로 만든 파일: N개
• 수정한 파일: N개
• 커밋 안 된 변경: 있음/없음

📝 문서 업데이트 제안 (doc-updater)
• [파일명]: [내용] (우선순위)
  ...

⚡ 자동화 제안 (automation-scout)
• [패턴]: [방법] (절약 효과)
  ...

🎓 오늘 배운 것 (learning-extractor)
• [주제]: [핵심 내용]
  ...

📌 다음에 할 일 (followup-suggester)
• [작업]: [이유] (우선순위)
  ...

🔍 검증 결과 (duplicate-checker)
• 중복 제거: N건 / 병합: N건
═══════════════════════════════════════
```

## Step 5: 사용자 선택 + 실행

통합 보고서 출력 후, AskUserQuestion으로 실행할 작업을 선택받는다.

### 선택지 제공

AskUserQuestion을 사용하여 다음 선택지를 제공한다:

```
질문: "어떤 작업을 실행할까요?"
옵션 (복수 선택 가능):
  1. 커밋 — 변경 사항을 커밋한다
  2. 문서 업데이트 — 제안된 문서 수정을 실행한다
  3. 자동화 생성 — 제안된 스킬/스크립트를 만든다
  4. 건너뛰기 — 아무것도 실행하지 않는다
```

### 실행 규칙

- **커밋 선택 시**: 변경 내용을 요약한 커밋 메시지를 자동 생성하고, 사용자 확인 후 커밋
- **문서 업데이트 선택 시**: doc-updater가 제안한 내용을 해당 파일에 반영
- **자동화 생성 선택 시**: automation-scout이 제안한 스킬/스크립트 파일을 생성
- **건너뛰기 선택 시**: 보고서만 출력하고 종료

> 선택된 작업만 실행한다. 선택되지 않은 작업은 건드리지 않는다.
